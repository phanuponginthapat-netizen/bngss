# คู่มือใช้งาน LINE OA โรงเรียน — สำหรับครู / ผู้ปกครอง / นักเรียน

---

## 🟢 เริ่มต้น — แอด LINE โรงเรียน

1. เปิดแอป LINE → กดปุ่ม **เพิ่มเพื่อน** → สแกน QR Code ของโรงเรียน
   (หรือค้นหา ID เช่น `@school-id`)
2. กด **เพิ่มเพื่อน** → จะมีเมนูสวย ๆ ใต้ห้องแชท

---

## 🔗 ผูกบัญชีกับระบบโรงเรียน (ทำครั้งเดียว)

> ก่อนจะใช้เมนูทุกอย่าง ต้องผูกบัญชีก่อน

### วิธีผูก
1. พิมพ์ในห้องแชท: **`ผูกบัญชี`**
2. บอทจะถามรหัส:
   - **นักเรียน/ผู้ปกครอง** → ใส่ **รหัสนักเรียน** (เช่น `12345`)
   - **ครู/พนักงาน** → ใส่ **รหัสพนักงาน** (เช่น `T-001`)
3. บอทจะถามวันเกิด — ใส่เป็นรูปแบบ **`DD/MM/YYYY`** ปี ค.ศ. (เช่น `15/05/2010`)
4. ✅ ผูกบัญชีสำเร็จ — เมนูจะเปลี่ยนเป็นเมนูของ role คุณอัตโนมัติ

### ผปค. 1 คนผูกได้กี่นักเรียน?
- LINE 1 บัญชีสามารถผูกได้ **หลายนักเรียน** (เช่น ผปค.มีลูก 3 คน)
- นักเรียน 1 คนผูกได้สูงสุด **3 บัญชี LINE** (เช่น พ่อ + แม่ + ตา)

### ยกเลิกการผูก
พิมพ์ **`ยกเลิกผูก`** → บอทจะลบทุก link ของบัญชี LINE นี้

## 👨‍👩‍👧 เมนูสำหรับ ผู้ปกครอง / นักเรียน

| ปุ่ม / คำสั่งพิมพ์ | ใช้ทำอะไร |
|--------------------|-----------|
| **ผลการเรียน** หรือ `เกรด` | ดูคะแนน + เกรดทุกวิชา (Carousel เลื่อนซ้ายขวา) |
| **การเข้าเรียน** หรือ `เช็คชื่อ` | สรุปการมาเรียน 30 วันล่าสุด |
| **ตารางสอน** หรือ `ตาราง` | ดูตารางเรียนสัปดาห์นี้ |
| **พฤติกรรม** | ประวัติคะแนนความประพฤติ 30 วัน |
| **ลา** | ยื่นใบลาออนไลน์ (เปิดฟอร์ม LIFF) |
| **ข่าวสาร** | ข่าวประชาสัมพันธ์ล่าสุด |

### การยื่นใบลาผ่าน LINE
**วิธี A — พิมพ์ทีละขั้น:**
1. พิมพ์ **`ลา`** → เลือกประเภท (ป่วย/กิจ)
2. ใส่วันที่เริ่ม → วันที่สิ้นสุด → เหตุผล
3. กด **ยืนยัน** → ระบบบันทึก + แจ้งครูประจำชั้น

**วิธี B — กดปุ่ม "ลา" ใน Rich Menu:**
- เปิดฟอร์ม LIFF กรอกเสร็จในจอเดียว → กดส่ง

### การแจ้งเตือนอัตโนมัติที่ ผปค.จะได้รับ
- 🚪 **บุตรหลานเข้าโรงเรียน** — เมื่อสแกนหน้าผ่านกล้อง
- 🇹🇭 **บุตรหลานเช็คชื่อหน้าเสาธง** — ตอนเข้าแถวเช้า
- 📌 **บุตรหลานขาดเรียน** — เมื่อครูบันทึก
- ⭐ **บุตรหลานทำดี** / ⚠️ **พฤติกรรมที่ควรปรับปรุง**
- 📊 **ผลคะแนน** — เมื่อครูบันทึกคะแนน/เกรด
- 📅 **สรุปประจำวัน 06:30 น.** (ถ้าเปิด opt-in)

## 👨‍🏫 เมนูสำหรับ ครู

| ปุ่ม / คำสั่งพิมพ์ | ใช้ทำอะไร |
|--------------------|-----------|
| **เช็คชื่อ** | เช็คชื่อนักเรียนห้องประจำชั้นทันทีจาก LINE (เปิด LIFF) |
| **วิชาฉัน** หรือ `วิชา` | ดูวิชาที่สอน + ห้องที่สอน (Carousel) |
| **สรุปห้อง** หรือ `ห้องฉัน` | สถิติห้องประจำชั้นวันนี้ (มา/ขาด/สาย/ลา) |
| **สอนแทน** | ดูคาบที่ต้องสอนแทนวันนี้ |
| **ลา** | ยื่นใบลา (ป่วย/กิจ/พักร้อน) ถึง ผอ. |
| **ข่าวสาร** | ข่าวประกาศ |

### เช็คชื่อผ่าน LINE
1. กดปุ่ม **เช็คชื่อ** ใน Rich Menu → เปิดฟอร์ม LIFF
2. รายชื่อนักเรียนห้องประจำชั้นจะแสดงทั้งหมด (default = มา)
3. กดปุ่ม **มา / ขาด / สาย / ลา** ของนักเรียนแต่ละคน
4. กด **บันทึก** → ข้อมูลเข้าระบบทันที + ผปค.ของคนที่ขาดได้รับแจ้งเตือน

### Daily Digest (สรุปประจำวัน)
ครูที่เปิด Daily Digest จะได้รับข้อความตอน **06:30 น.**:
- ตารางสอนวันนี้ (ทุกคาบ)
- คาบสอนแทนที่ได้รับมอบหมาย

## ❓ คำถามที่พบบ่อย

**Q: ผูกบัญชีแล้วทำไมเมนูยังเป็นแบบเดิม?**
A: ปิดห้องแชท → เปิดใหม่ หรือกดที่ตัวเมนู (▼) ปุ่มจะรีเฟรช

**Q: ลืมรหัสนักเรียน?**
A: ติดต่อครูประจำชั้น หรือฝ่ายวิชาการ

**Q: อยากปิดแจ้งเตือนตอนกลางคืน?**
A: กดบล็อกข้อความ OA ใน LINE ก็ได้ — หรือใช้ฟีเจอร์ Mute ของ LINE

**Q: ส่งข้อความผิด/ส่งซ้ำ ต้องทำยังไง?**
A: พิมพ์ **`ยกเลิก`** ในขณะตอบโต้กับบอท เพื่อยกเลิก flow ที่ค้างอยู่

**Q: บอทไม่ตอบ?**
A: ลองพิมพ์ **`เมนู`** หรือ **`help`** เพื่อรีเฟรชเมนูคำสั่ง

**Q: เปลี่ยน LINE ใหม่ ต้องทำยังไง?**
A: ในเครื่องเก่า พิมพ์ **`ยกเลิกผูก`** ก่อน → เครื่องใหม่แอด OA แล้วทำขั้นตอนผูกบัญชีใหม่อีกครั้ง
