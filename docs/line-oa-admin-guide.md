# คู่มือ LINE OA — ฝั่งผู้ดูแลระบบ (Admin Setup Guide)

คู่มือสำหรับ Admin/IT ในการตั้งค่า LINE Official Account เชื่อมกับระบบโรงเรียน

---

## 1. ภาพรวมระบบ

ระบบเชื่อม LINE OA ทำได้ 3 ระดับ:

| ระดับ | ใช้ทำอะไร | สิ่งที่ต้องตั้ง |
|------|----------|--------------|
| **A. แจ้งเตือนทางเดียว** (Push Notification) | ส่งข้อความหา ผปค./ครู เมื่อมีเหตุการณ์ (สแกนหน้า, ขาดเรียน, คะแนน, พฤติกรรม) | Channel Access Token + Channel Secret |
| **B. Chatbot โต้ตอบ** (Webhook) | ผู้ใช้พิมพ์คำสั่งใน LINE เช่น "ผลการเรียน", "ลา", "เช็คชื่อ" | + ตั้ง Webhook URL ใน LINE Console |
| **C. LIFF Mini-app** | เปิดหน้าฟอร์มสวย ๆ ในแอป LINE (ยื่นใบลา, ดูคะแนน, เช็คชื่อ) | + สร้าง LIFF app + ใส่ LIFF ID |

---

## 2. ขั้นตอนการตั้งค่า (ครั้งแรก)

### 2.1 สร้าง LINE Official Account
1. ไปที่ <https://www.linebiz.com/th/entry/> สมัคร LINE OA (ฟรี)
2. ตั้งชื่อ OA (เช่น "โรงเรียน xxx") + อัปโหลดโลโก้

### 2.2 สร้าง Messaging API Channel
1. ไปที่ <https://developers.line.biz/console/>
2. สร้าง Provider → สร้าง Channel ประเภท **Messaging API**
3. ผูกกับ LINE OA ที่สร้างไว้
4. ในแท็บ **Messaging API** → คัดลอกค่าต่อไปนี้:
   - **Channel Access Token (Long-lived)** → กดปุ่ม Issue
   - **Channel Secret** (อยู่ในแท็บ Basic settings)

### 2.3 ใส่ข้อมูลในระบบ
1. เข้าระบบด้วยบัญชี Admin → เมนู **Admin → ตั้งค่า LINE**
2. กรอก:
   - Channel Access Token
   - Channel Secret
   - เปิดสวิตช์ **เปิดใช้งาน LINE Bot**
   - เปิดสวิตช์ **เปิดใช้งาน LINE Notify**
3. กดบันทึก

### 2.4 ตั้ง Webhook URL ใน LINE Console
1. คัดลอก **Webhook URL** ที่แสดงในหน้าตั้งค่า LINE (รูปแบบ: `https://xxx.supabase.co/functions/v1/line-webhook`)
2. กลับไปที่ LINE Developers Console → Messaging API
3. วาง URL ลงในช่อง **Webhook URL** → กด **Update**
4. เปิดสวิตช์ **Use webhook** = ON
5. ปิด **Auto-reply messages** = OFF (ไม่งั้นข้อความ default จะรบกวน)
6. ปิด **Greeting messages** = OFF หรือเก็บไว้ก็ได้
7. กดปุ่ม **Verify** ต้องได้ "Success"

### 2.5 ทดสอบส่งข้อความ
- ในหน้าตั้งค่า LINE → กรอก LINE User ID ของตัวเอง (หาได้จากใน LINE app)
- กด "ส่งข้อความทดสอบ" → ต้องเด้งใน LINE

---

## 3. ตั้งค่า Rich Menu (เมนูสวย ๆ ใต้ห้องแชท)

### 3.1 สร้างอัตโนมัติ
1. หลังจากตั้ง Token + Secret แล้ว ไปที่ **Admin → ตั้งค่า LINE**
2. ในการ์ด **Rich Menu** → กดปุ่ม **สร้าง/อัปเดต Rich Menu**
3. ระบบจะสร้าง 3 เมนูในบัญชี LINE ของคุณ:
   - **Default** — สำหรับคนที่ยังไม่ผูกบัญชี (ปุ่ม "ผูกบัญชี", "ข่าวสาร")
   - **Parent/Student** — เมนู 6 ปุ่ม (ผลการเรียน, การเข้าเรียน, ตารางสอน, พฤติกรรม, ข่าวสาร, ลา)
   - **Teacher** — เมนู 6 ปุ่ม (เช็คชื่อ, วิชาฉัน, สรุปห้อง, สอนแทน, ข่าวสาร, ลา)
4. ระบบจะตั้ง Default menu อัตโนมัติ และจะสลับเมนูตาม role เมื่อผู้ใช้ผูกบัญชี

### 3.2 ระบบสลับเมนูตาม Role
- ผู้ใช้แอด LINE OA → ได้ **Default menu** ทันที
- ผู้ใช้พิมพ์ "ผูกบัญชี" + กรอกรหัสนักเรียน/พนักงาน + ยืนยันวันเกิด → ระบบจะสลับเป็นเมนูตาม role โดยอัตโนมัติ

## 4. ตั้งค่า LIFF Mini-app

LIFF ใช้สำหรับเปิดหน้าเว็บในแอป LINE (ฟอร์มยื่นใบลา, ดูคะแนน, เช็คชื่อแบบเร็ว)

### 4.1 สร้าง LIFF app
1. ใน LINE Developers Console → เลือก Channel ที่สร้างไว้
2. ไปแท็บ **LIFF** → กด **Add**
3. กรอก:
   - **LIFF app name**: เช่น "ใบลา"
   - **Size**: **Tall** (เต็มจอเกือบทั้งหมด)
   - **Endpoint URL**: `https://<โดเมนของคุณ>/liff/leave`
   - **Scope**: เลือก `profile`, `openid`
   - **Bot link feature**: On (Aggressive)
4. กด **Add** → ระบบจะให้ **LIFF ID** เช่น `1234567890-abcdef`

### 4.2 ทำซ้ำสำหรับหน้าอื่น
สร้าง LIFF app เพิ่มสำหรับ:
- `/liff/grades` — ดูคะแนน
- `/liff/attendance` — เช็คชื่อ (ครู)

### 4.3 ใส่ LIFF ID ในระบบ
1. **Admin → ตั้งค่า LINE → การ์ด LIFF Mini-app**
2. ใส่ LIFF ID ของ "ใบลา" (อันแรกที่สร้าง) — ระบบใช้ตัวนี้เป็น base
3. กดบันทึก

> **หมายเหตุ**: ถ้าต้องการ Rich Menu ที่กดแล้วเปิด LIFF ให้ใช้ URL `https://liff.line.me/<LIFF_ID>` ผูกกับปุ่มใน Rich Menu

## 5. การแจ้งเตือนอัตโนมัติที่ระบบทำให้ (Triggers)

ระบบจะส่งข้อความเข้า LINE ของ **ผู้ปกครอง** อัตโนมัติเมื่อ:

| เหตุการณ์ | ข้อความที่ส่ง |
|----------|--------------|
| นักเรียนสแกนหน้าเข้าโรงเรียน | 🚪 เข้าโรงเรียน + เวลา |
| นักเรียนสแกนหน้าเข้าแถวเสาธง | 🇹🇭 เช็คชื่อหน้าเสาธง + เวลา |
| ครูเช็คชื่อว่าขาด | 📌 บุตรหลานขาดเรียน |
| ครูบันทึกพฤติกรรม (+/-) | ⭐ พฤติกรรมดี / ⚠️ พฤติกรรมที่ควรปรับปรุง |
| ครูบันทึกคะแนน/เกรด | 📊 ผลคะแนน + วิชา + เกรด |

ส่งหาบัญชี LINE ผู้ใช้ที่ลงทะเบียน (สูงสุด 3 บัญชี LINE ต่อนักเรียน 1 คน — เช่น พ่อ แม่ ผปค.)

### 5.1 Daily Digest (สรุปประจำวัน 06:30 น.)
- เปิด/ปิดได้รายคน (ผ่านการตั้งค่าใน DB `line_user_preferences.digest_enabled`)
- ผปค./นักเรียน: สรุปการเข้าเรียนวันนี้ + พฤติกรรม 7 วันล่าสุด
- ครู: ตารางสอนวันนี้ + คาบสอนแทน

## 6. โควต้าและค่าใช้จ่าย LINE

| แผน | ข้อความ Push/เดือน | ราคา |
|-----|-----------------|------|
| Free | 200 | ฟรี |
| Light | 5,000 | 1,200 บาท/เดือน |
| Standard | 30,000 | 1,500 บาท/เดือน |

> **ทิป**: ข้อความตอบกลับ (Reply) ที่ผู้ใช้กดส่งคำสั่งเข้ามาก่อน **ไม่นับ** โควต้า — นับเฉพาะ Push (แจ้งเตือนอัตโนมัติ + Daily Digest)

## 7. การแก้ปัญหา (Troubleshooting)

| อาการ | สาเหตุ | วิธีแก้ |
|------|--------|---------|
| Verify webhook ไม่ผ่าน | URL พิมพ์ผิด หรือยังไม่ deploy | คัดลอก URL จากในระบบใหม่ |
| ส่งข้อความทดสอบไม่เด้ง | LINE User ID ผิด หรือผู้ใช้ยังไม่แอด OA | ผู้ใช้ต้องแอด OA ก่อน |
| Bot ไม่ตอบเมื่อพิมพ์ | สวิตช์ Bot ปิด หรือ Webhook ไม่ผ่าน | เปิดสวิตช์ + Verify webhook |
| Rich Menu ไม่ขึ้น | ยังไม่กดสร้าง หรือ Token ผิด | กดปุ่มสร้าง Rich Menu ใหม่ |
| LIFF เปิดไม่ได้ ขึ้น "ยังไม่ได้ตั้งค่า LIFF ID" | ยังไม่ใส่ LIFF ID | ใส่ใน Admin → ตั้งค่า LINE |
| ข้อความซ้ำ 2 ครั้ง | Trigger ทำงานซ้ำ หรือ user_id ซ้ำใน slot | ตรวจ student.line_user_id slots ห้ามมีค่าซ้ำกัน |

## 8. ความปลอดภัย

- **Channel Secret** ใช้ verify signature ของทุกข้อความที่ LINE ส่งมา — ห้ามรั่ว
- **Channel Access Token** เป็น long-lived (ไม่หมดอายุ) — ถ้ารั่วต้อง **Reissue** ทันที
- ระบบเก็บ Token/Secret ใน table `school_settings` ที่อ่านได้เฉพาะ admin/director (มี RLS)
- Webhook ทุก request มีการ verify HMAC-SHA256 signature ก่อนประมวลผล
