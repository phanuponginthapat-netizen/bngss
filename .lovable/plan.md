# นำระบบสแกนหน้า ConnextedScan มาแทนคีออสเดิม

## เป้าหมาย
ยกโปรแกรมสแกนหน้าของ ConnextedScan (ตัวเต็ม: มีฐานข้อมูลในเครื่อง คิวส่งออฟไลน์ หน้าจอคีออสในตัว ควบคุมประตู จัดการไฟ/พักหน้าจอ เสียงพูด และอัปเดตตัวเองอัตโนมัติ) มาแทน FaceGate agent เดิมของเรา แล้วต่อเข้ากับฐานข้อมูลและรายงานของ BNGSS ให้ใช้งานได้ทั้งตอนมีเน็ตและเน็ตล่ม

ข้อดีที่ได้ทันที: ใช้โมเดลตัวเดียวกับที่เราลงทะเบียนใบหน้าไว้แล้ว (SCRFD + ArcFace 512 มิติ) จึงไม่ต้องลงทะเบียนใบหน้าใหม่ทั้งโรงเรียน

## สิ่งที่จะทำ

### 1. ย้ายโปรแกรมสแกนเข้ามาในโปรเจกต์
- แทนที่ `scripts/kiosk/facegate-agent/` ด้วยชุดใหม่ `scripts/kiosk/connexted-agent/` (agent, face_engine, localdb, local_api, local_ui, local_admin_ui, door, power, clock, voice, rules)
- ปรับค่าเริ่มต้นให้ชี้มาที่ระบบเรา: ที่อยู่เซิร์ฟเวอร์ ชื่อไฟล์ปลายทาง และรหัสเครื่อง
- ตัดส่วนที่เราไม่ใช้ออกให้เหลือเท่าที่จำเป็น และคงโหมด "ฮับ + เครื่องลูก" ในวง LAN ไว้

### 2. สร้างชุดบริการฝั่งระบบให้ตรงกับที่โปรแกรมเรียกใช้
เพิ่มฟังก์ชันหลังบ้านชุดเดียว `kiosk-api` ที่รองรับเส้นทางย่อยทั้งหมดของโปรแกรม แล้วแปลงข้อมูลเข้าโครงสร้างจริงของ BNGSS:
- ดึงข้อมูล (รายชื่อ + ใบหน้า + ค่าตั้งค่า) แบบส่งเฉพาะส่วนที่เปลี่ยน
- ส่งผลสแกนเข้า-ออก เข้าตาราง `attendance` และ `face_scan_logs` เดิม ผ่านกติกาเดิม (เวลาไทย, สาย 08:30, กันสแกนซ้ำ)
- คำนวณใบหน้าที่เพิ่งลงทะเบียนแล้วส่งค่ากลับ
- แจ้งเตือนคนแปลกหน้า, บันทึกผู้มาติดต่อ, คำสั่งเปิดประตู, คำสั่งเปิด/ปิดเครื่อง, ภาพสดหน้าตู้
- รับรองเครื่องด้วยรหัสเครื่อง (device key) แทนการล็อกอิน

### 3. ทะเบียนเครื่องคีออส
- ตารางใหม่ `kiosk_devices`: ชื่อเครื่อง รหัสเครื่อง ทิศทางเริ่มต้น (เข้า/ออก) เวอร์ชันโปรแกรม สถานะกล้อง/ประตู/พื้นที่ว่าง เวลาติดต่อล่าสุด — พร้อมสิทธิ์เข้าถึงและนโยบายความปลอดภัย
- ค่าตั้งค่าคีออส (เกณฑ์ความเหมือน, หน่วงคนถัดไป, ตรวจคนจริง, น้ำหนักโครงหน้า, ประตู, เสียง) เก็บใน `school_settings` คีย์ `kiosk_config` ที่มีอยู่แล้ว แล้วแปลงส่งให้โปรแกรม

### 4. หน้าเว็บของเรา
- `/face-kiosk` เปลี่ยนมาคุยกับโปรแกรมใหม่ และถ้าไม่พบโปรแกรมยังสแกนผ่านเบราว์เซอร์ได้เหมือนเดิม
- หน้า "ตั้งค่าคีออส" (admin): เพิ่มรายการเครื่อง สร้าง/คัดลอกรหัสเครื่อง ดูสถานะออนไลน์/เวอร์ชัน และดาวน์โหลดตัวติดตั้งชุดใหม่ (Windows/Linux)

### 5. ออฟไลน์
- โปรแกรมเก็บรายชื่อ ใบหน้า และค่าตั้งค่าไว้ในเครื่อง สแกนต่อได้แม้เน็ตล่ม
- ผลสแกนที่ส่งไม่ได้จะเข้าคิวในเครื่องและส่งเองเมื่อเน็ตกลับมา (กันซ้ำด้วยรหัสอ้างอิงต่อรายการ)
- หน้าจอคีออสและหน้าผู้ดูแลในเครื่องเปิดใช้ได้โดยไม่ต้องมีเน็ต

### 6. ตรวจสอบก่อนปิดงาน
- ทดสอบ: ดึงข้อมูลครั้งแรก, สแกนสำเร็จ, สแกนซ้ำถูกกัน, ตัดเน็ตแล้วสแกน, ต่อเน็ตแล้วคิวถูกส่ง
- ตรวจว่ารายงานประจำวันและสรุปไลน์ยังนับตรงเหมือนเดิม

## หมายเหตุทางเทคนิค
- โมเดล `det_500m.onnx` + `w600k_mbf.onnx` เหมือนของเดิม → ใบหน้า 512 มิติที่ลงทะเบียนไว้ใช้ต่อได้ทันที
- เส้นทางเดิม `/api/public/kiosk/*` ของ ConnextedScan จะถูก map ไปยังฟังก์ชัน `kiosk-api` ของเรา โดยแก้ค่า base URL ในตัวโปรแกรม
- ฟังก์ชันเดิม `kiosk-face-download` / `kiosk-face-register` / `kiosk-offline-alert` คงไว้เพื่อไม่ให้เครื่องเก่าพัง แล้วค่อยเลิกใช้ภายหลัง
- งานนี้แตะทั้งสคริปต์เครื่องคีออส ฟังก์ชันหลังบ้าน ฐานข้อมูล และหน้าเว็บคีออส/ตั้งค่า
