# โปรแกรมตู้สแกน FaceGate (เครื่อง Intel Atom + เว็บแคม)

## ติดตั้ง

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## ตั้งค่า

นำรหัสเครื่องจากหน้า "ตั้งค่าระบบ → เครื่องตู้สแกน" มาใส่:

```bash
export FACEGATE_DEVICE_KEY=รหัสเครื่องที่คัดลอกมา
export FACEGATE_CLOUD_URL=https://dlkyxvhnnffblerwedjz.supabase.co/functions/v1
python agent.py
```

โปรแกรมจะเปิดที่ `http://127.0.0.1:8899` แล้วเปิดหน้าเว็บ `/kiosk` บนเครื่องเดียวกัน (โหมดเต็มจอ)

## การทำงาน

- ดึงรายชื่อนักเรียน ค่าตั้งค่า และข้อมูลใบหน้าจากระบบทุก 30 วินาที
- คำนวณใบหน้าจากรูปที่ลงทะเบียนใหม่ด้วย ArcFace (InsightFace buffalo_l) แล้วส่งกลับ
- รับภาพจากหน้าเว็บ เทียบใบหน้า ตรวจว่าเป็นคนจริง แล้วบันทึกเข้า-ออกให้อัตโนมัติ
- คนที่ไม่ได้ลงทะเบียนหรือถูกระงับจะไม่ถูกบันทึกและระบบจะแจ้งเสียงปฏิเสธ
- **สแกนตามคิวอัตโนมัติ**: หากมีหลายใบหน้าในกรอบ ระบบจะสแกนใบหน้าที่ใหญ่สุด (คนที่เดินเข้ามาใกล้กล้อง) ทันที คนที่ยืนรอด้านหลังไม่ต้องถอยออกไปก่อน

## ตั้งค่าความเร็ว (เครื่องสเปกต่ำ)

โปรแกรมตรวจเองว่าเครื่องสแกนแรงแค่ไหน แล้วเลือกปริมาณงานต่อ 1 ภาพ

- `eco` — เครื่อง Celeron / Atom (เช่น J1900, HP Pavilion x2): ตอนไม่มีคนหน้ากล้องจะพัก
  ไม่คำนวณใบหน้าทุกภาพ แต่เมื่อมีคนเข้ามาจะตรวจทันที คนที่ยืนนิ่งก็ได้รับการตรวจ
  อย่างน้อยทุก 1 วินาที
- `balanced` / `full` — เครื่องที่แรงกว่า: ค้นหาใบหน้าครบทุกวิธีเหมือนเดิม

ถ้าต้องการกำหนดเอง ใส่ใน `facegate.env`:

```
FACEGATE_POWER_MODE=eco     # eco | balanced | full
FACEGATE_DET_SIZE=320       # ใหญ่ขึ้น = หาใบหน้าไกลได้ดีขึ้น แต่ช้าลง
```

ดูความเร็วจริงของเครื่องได้ที่ `/health` (ช่อง `perf` = จำนวน ms ต่อการตรวจ 1 ครั้ง)

## สแกน QR บัตรนักเรียน (กรณีสแกนหน้าไม่ติด)

ให้นักเรียนชู QR บนบัตรนักเรียนหน้ากล้องตัวเดียวกัน ระบบรับเฉพาะ QR ที่เป็นรหัสนักเรียน
ของโรงเรียน (QR เชื่อม LINE หรือ QR อื่นจะไม่ถูกนับ) และถ่ายรูปทั้งภาพเก็บไว้ให้ครูตรวจย้อนหลัง
ว่าใครเป็นคนถือบัตร ปิดได้ด้วยค่า `qr_card_enabled = false` ในตั้งค่าเครื่อง



## ใช้ผ่าน Electron

หากใช้ไฟล์ Electron ที่แพ็กไว้ ไม่จำเป็นต้องรัน `python agent.py` เอง Electron จะเรียก agent อัตโนมัติหลังตั้งค่ารหัสเครื่อง

## อัปเดตอัตโนมัติ (รุ่น 1.13.0 เป็นต้นไป)

ติดตั้งรุ่นนี้ครั้งแรกด้วย install.sh บน Linux หรือ FaceGateSetup.exe บน Windows แล้วเปิดเครื่องและเชื่อมอินเทอร์เน็ตช่วง 03:00–03:59 เวลาไทย เครื่องต้องไม่มีคนหน้ากล้องและไม่มีรายการรอส่ง อัปเดตจะตรวจ SHA-256 จากทะเบียนรุ่นที่ Cloud ยืนยัน ไม่เปลี่ยนค่าตั้งค่า/แคช/รายการรอส่ง และย้อนรุ่นเมื่อโปรแกรมใหม่ไม่พร้อมภายใน 180 วินาที

Windows ต้องติดตั้งด้วยสิทธิ์ผู้ดูแลในบัญชีที่ใช้งานตู้ และคงบัญชีนั้นเข้าสู่หน้าจอไว้ งานอัปเดตไม่ทำงานแบบ SYSTEM; Linux ต้องเปิดผ่านตัวเปิด facegate ที่ติดตั้งให้ ไม่ใช่เรียก agent.py โดยตรง ปิดอัปเดตเฉพาะเครื่องได้ด้วย FACEGATE_AUTO_UPDATE=0; ค่าปิดอัปเดตที่โรงเรียนบันทึกไว้ยังคงมีผล
