# แผน: Standalone ครบชุด (.exe) + ลิงก์ระบบหลักสำหรับเขต

## เป้าหมาย
1. โรงเรียนติดตั้งระบบทั้งหมดบน PC เครื่องเดียวด้วยไฟล์ `setup.exe` ใช้ HDD เก็บทุกอย่าง (ไม่ใช้ Cloud และ Google Drive)
2. เครื่องในโรงเรียนส่ง "ตัวเลขสรุป" ขึ้นระบบหลักเมื่อมีเน็ต ให้เขตดูภาพรวมทุกโรงเรียนได้ในหน้าเดียว
3. โรงเรียนที่ใช้ Cloud และ Standalone แสดงรวมกันในหน้าเขตเดียวกัน

## ส่วนที่ 1: ระบบหลักและหน้าภาพรวมเขต
- ทะเบียนโรงเรียนในระบบหลัก: รหัสโรงเรียน, ชื่อ, เขต, ประเภท (Cloud/Standalone), สถานะ, ส่งข้อมูลครั้งล่าสุด
- ผู้ดูแลกลางสร้าง "รหัสลงทะเบียน" ให้แต่ละโรงเรียน (ใช้ครั้งเดียว ได้กุญแจส่งข้อมูลประจำโรงเรียน)
- ช่องรับข้อมูลสรุป: รับเฉพาะตัวเลขสรุปรายวัน (จำนวนนักเรียน/ครู, อัตรามา-ขาด-สาย, ผลการเรียนรวมรายชั้น/วิชา, สถานะระบบ) ไม่รับข้อมูลรายคน
- หน้าภาพรวมเขต: ตารางทุกโรงเรียน, กราฟการมาเรียน, ผลการเรียน, โรงเรียนที่ไม่ได้ส่งข้อมูลเกิน 2 วัน, ดาวน์โหลด Excel
- สิทธิ์: บทบาท "เจ้าหน้าที่เขต" เห็นเฉพาะโรงเรียนในเขตตัวเอง

## ส่วนที่ 2: ฝั่งโรงเรียน (ใช้ได้ทั้ง Cloud และ Standalone)
- หน้า "เชื่อมระบบเขต": ใส่ URL ระบบหลัก + รหัสลงทะเบียน กดทดสอบ และดูประวัติการส่ง
- ต่อยอดงานส่งข้อมูลให้เขตที่มีอยู่แล้ว (snapshot รายคืน + คิวส่งซ้ำเมื่อเน็ตหลุด) ให้ชี้ไประบบหลักได้
- ส่งอัตโนมัติทุกคืน และส่งค้างเองเมื่อเน็ตกลับมา

## ส่วนที่ 3: Standalone ใช้ HDD ทั้งระบบ
- พื้นที่เก็บไฟล์: เปลี่ยนจาก Google Drive เป็นโฟลเดอร์บน HDD เมื่ออยู่โหมด Standalone (คลังไฟล์เก่า, สำรองข้อมูล, LINE Vault, สื่อ AR)
- ปิดงานย้ายไฟล์ขึ้น Drive และโควตา free tier ในโหมด Standalone (ไม่จำเป็น)
- สำรองข้อมูลทุกคืนลง HDD + External HDD (มีแล้ว ปรับให้เก็บไฟล์ด้วย)
- ฟีเจอร์ที่ต้องใช้เน็ต (LINE, AI) ทำงานเมื่อมีเน็ต ไม่มีเน็ตก็ไม่ทำให้ระบบค้าง

## ส่วนที่ 4: ตัวติดตั้ง setup.exe (Windows)
- ตัวติดตั้งแบบกด Next: ตรวจ/ลง WSL2 + Docker, เลือกโฟลเดอร์ HDD ที่เก็บข้อมูล, เลือกโหมด (ในโรงเรียนอย่างเดียว / ผสม), ใส่ชื่อและรหัสโรงเรียน, สร้างบัญชีผู้ดูแลคนแรก
- ไอคอนใน Start Menu: เปิดระบบ / สำรองข้อมูล / กู้คืน / อัปเดต / ถอนการติดตั้ง
- เปิดเครื่องแล้วระบบเริ่มทำงานเอง
- สร้าง .exe อัตโนมัติบน GitHub Actions และวางลิงก์ดาวน์โหลดในหน้าตั้งค่าระบบ
- Linux ใช้สคริปต์ติดตั้งตัวเดิม (ปรับให้ตรงกัน)

## ส่วนที่ 5: ย้ายข้อมูลและคู่มือ
- เครื่องมือย้ายข้อมูลจาก Cloud มาเครื่องในโรงเรียน (ฐานข้อมูล + ไฟล์ + ไฟล์บน Drive)
- คู่มือภาษาไทย: ติดตั้ง, ลงทะเบียนกับเขต, สำรอง/กู้คืน, สเปกเครื่อง (RAM 8 GB+, SSD)

## ข้อจำกัด
- ยังทดสอบบน PC จริงไม่ได้ ต้องลองกับเครื่องสำรองก่อนใช้จริง
- ไฟล์ .exe ยังไม่มีลายเซ็นดิจิทัล Windows อาจเตือนตอนติดตั้ง (กด "Run anyway")

## รายละเอียดทางเทคนิค
- ระบบหลักใช้ backend ปัจจุบัน: ตาราง `district_schools`, `district_enrollment_codes`, `district_school_snapshots` + RLS ตามบทบาท `district_officer`
- Edge function `district-ingest` (ตรวจกุญแจต่อโรงเรียนผ่าน header, จำกัดอัตรา, idempotent ต่อโรงเรียน/วัน)
- ปรับ `district-nightly-snapshot` และ `district-outbox-worker` ให้ส่งไป URL ระบบหลักที่ตั้งค่าได้
- เพิ่ม `STORAGE_PROVIDER: "local"` ใน runtimeConfig; edge function `local-storage` เขียนไฟล์ลง volume ที่ mount จาก HDD; storage-tier/drive-archive เลือก provider ตามโหมด
- Installer: Inno Setup เรียก `install-windows.ps1`/`install.sh`, ตัวเลือก `DATA_DIR` mount เป็น volume ของ Docker; workflow `build-standalone-installer.yml`
